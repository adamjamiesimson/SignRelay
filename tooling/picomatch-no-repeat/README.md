# Picomatch compatibility fork

Based on MIT-licensed Picomatch 4.0.7 (tag `4.0.7`, commit `6bb4067`). The original license and library entry points are included. The parser fails immediately on `+(...)` and `*(...)`, including inside other extglobs, and disables raw suffix repetition. It also preserves the glob wildcard meaning of `?` after a `)` instead of emitting a regex quantifier. Stacking 38 raw optional groups previously exceeded a 1.8-second subprocess deadline on a short input. The audit regression now tests that case under a bounded subprocess.

The root npm override makes Vite, Vitest, tinyglobby and fdir resolve this same local package. npm’s advisory database keys on package identity, so its clean result does not verify this fork. Source review, lockfile and installed-resolution checks, and adversarial pattern tests cover the vendor patch. The fork is for trusted repository build and test patterns. Features such as custom regex state or callbacks can bypass glob syntax safeguards and are outside that trust boundary. Replace the fork once a compatible upstream release is verified.
