## 1. ASL regression and root causes

The path is: unmirrored camera/canvas pixels → MediaPipe Tasks gesture/hand, compact face and full pose observations → continuous hand histories at four temporal window lengths → explicit starter geometry plus separately segmented closed-set ASL TGCN inference → personal/starter/model arbitration → finite confidence and two-evidence confirmation → repeated-word block, prediction invalidation and history consumption. Generic motion segmentation gates model inference. Starter rules have their own motion criteria and can still confirm while the generic segment reports `moving`; blanket gating all starters would change established behavior and was not applied without broader evidence.

**Reproduced PR #28 defect:** its circle closure test removed PLEASE from the set of labels used by cross-window ambiguity arbitration. A shorter window could still propose THANK YOU. Losing competing evidence turned an abstention into a wrong acceptance, even though the completion test looked stricter in isolation. The real trace confirmed the added word came from `starter`, not the research model. A synthetic arc/outward-suffix counterexample provides deterministic coverage. Its geometry is constructed, not signing evidence.

**Implemented:** incomplete PLEASE geometry remains competing evidence for the ambiguity veto, while retaining PR #28's prohibition against emitting the incomplete circle. Completed positive circles, outward THANK YOU controls, both hands, varied speeds/framing, YES/SORRY discrimination, hand gaps and successive/held-sign tests remain. No numerical confidence, margin, closure or distance threshold changed. Model weights and tensor-slot mapping are unchanged.

The explicit `blockedStarter` branch already returns null when its direct prediction is blocked; it does not fall through to `latestPrediction`. A controlled worker test now covers that control. Confirmation evidence is additionally keyed by recognizer source so a personal, starter and model prediction cannot be intentionally combined as one streak. This source check is defensive hardening, not a measured accuracy gain.

**Remaining defect:** THANK YOU → PLEASE still occurs in the historical `.8033` recording. At the wrong confirmation, all 11–12 samples in the recognized window had usable shoulder references. The starter geometry classified a chest loop with normalized wrist excursions about 0.290 × 0.492 while generic motion still reported `moving`. Thus missing-pose fallback alone does not explain this failure. Sparse hand acquisition (15/37 frames in the whole recording), omitted initial articulation, per-frame coordinate changes and landmark errors remain plausible contributors; the available evidence does not establish their individual causal shares. A trajectory that passes these geometric tests is not proof of PLEASE. No threshold was tuned to this clip, and no claim is made that its semantic confusion is repaired.

## 3. Recognition lifecycle reliability

ASL's runtime previously ignored the AbortSignal supplied by the worker. It now uses bounded cancellable downloads with idle/deadline handling, reports loading separately from inference, checks cancellation between cooperative graph steps, retains completed cached weights, and prevents a failed old attempt from clearing a newer load. Actual-weight tests and a browser probe confirm cancellation and fresh/cached reuse without changing neural arithmetic.

The recognition worker now checks monotonic elapsed time as well as camera timestamps. A model result that took more than the existing 2.5-second evidence lifetime is discarded even when the camera timestamp stalls; cached model/personal results also expire by elapsed time. Source-specific confirmation streaks and reset cleanup are explicit. Earlier generation/session checks, latest-frame replacement, bounded matching workers, same-word suppression and personal-template compatibility remain.

Three new regression tests were demonstrated failing against the original source: lost incomplete-circle ambiguity evidence, ASL arithmetic ignoring cancellation, and a late model result surviving stalled camera time. Broader positive and negative synthetic controls pass. These software tests do not certify movement understanding, continuous signing, or real-world false-positive rates. The additional signed videos found no new incorrect acceptance or recall change, but no real negative footage validates a wider segmentation redesign. That work remains evidence-blocked.
