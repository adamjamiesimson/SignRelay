# ASL data sources for Project Rebirth

The trained experiment uses PopSign v1.0 only. The target vocabulary is HELLO, THANK YOU, PLEASE, YES and NO. SORRY is absent from the v1 game vocabulary. A publisher-labelled isolated sign supplies a clip boundary, but may contain preparation, recovery or a distinct accepted variant. Continuous webcam use adds boundary, framing and tracking conditions outside this corpus.

## Prior architectures and resource rights

- The [PopSign paper](https://proceedings.neurips.cc/paper_files/paper/2023/file/00dada608b8db212ea7d9d92b24c68de-Paper-Datasets_and_Benchmarks.pdf) reports an 84.2% closed-set top-1 LSTM result. Its capture protocol and output metric differ from webcam transcription and open-set acceptance.
- [The WLASL paper](https://arxiv.org/abs/1910.11006) compares visual and pose classifiers. The local Pose-TGCN conversion maps 55 MediaPipe joints to the checkpoint’s OpenPose format and retains an estimator and segmentation mismatch.
- [Self-supervised video recognition research](https://arxiv.org/abs/2309.02450) provides evidence that RGB can help isolated classification on WLASL. Any RGB or hybrid comparison here still needs a matched PopSign input, a lawful initialization and a measured CPU browser budget. No RGB checkpoint was acquired.
- Training uses pinned Google MediaPipe Gesture Recognizer, Face Landmarker and Pose Landmarker Lite assets from SignRelay’s verified runtime. MediaPipe is [Apache 2.0](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE). The derivative research artifacts contain aggregate statistical weights fitted from CC BY 4.0 PopSign landmarks. [Georgia Tech attribution and dataset terms](https://signdata.cc.gatech.edu/view/datasets/popsign_v1_0/) apply.
